# OPEX LÍDER — Visión del producto

**Versión:** 1.0
**Estado:** Visión inicial del proyecto

## 1. Propósito

Construir un libro web interactivo en español que permita comprender y aplicar conceptos de liderazgo y excelencia operacional mediante explicaciones, ejemplos, diagramas y experiencias visuales.

Principio central: primero comprender, después sorprender.

## 2. Público objetivo

Líderes, supervisores, coordinadores y responsables de equipos o procesos.

El contenido debe ser útil en diferentes industrias, como manufactura, logística, mantenimiento y servicios.

## 3. Experiencia del lector

El usuario podrá:

- Leer capítulos organizados como un libro.
- Navegar entre aproximadamente 50 y 100 páginas.
- Buscar conceptos específicos.
- Explorar tableros, indicadores y procesos visuales.
- Activar diagramas y pequeñas simulaciones.
- Utilizar páginas para explicar conceptos en reuniones.
- Guardar localmente su progreso y marcadores.

## 4. Contenido principal

El libro abordará:

- Liderazgo y desarrollo de personas.
- Gestión de procesos.
- Estrategia y objetivos.
- Indicadores de desempeño (KPI).
- Gestión diaria.
- Identificación y resolución de problemas.
- Mejora continua.
- Estandarización y disciplina operacional.
- Desarrollo de autonomía.

La estructura editorial definitiva se validará posteriormente.

## 5. Enfoque visual

Diseño editorial oscuro con predominio del azul.

Utilizar diagramas, flujos, tableros reinterpretados y representaciones interactivas para facilitar el aprendizaje.

Priorizar HTML, CSS y SVG. Utilizar animación avanzada o 3D únicamente cuando aporten comprensión.

Las visualizaciones deben funcionar correctamente en escritorio, tabletas y móviles.

## 6. Fundamento del contenido

El conocimiento procederá de:

1. Materiales de referencia sobre excelencia operacional.
2. Investigación y fuentes técnicas verificables.
3. Prácticas industriales contextualizadas.
4. Síntesis pedagógica original de OPEX LÍDER.

Distinguir evidencia, práctica, referencia y propuesta propia.

No copiar literalmente documentos, formatos ni identidad de empresas.

## 7. Alcance técnico de V1

Aplicación web predominantemente estática.

Tecnología inicial: Astro y TypeScript.

Las interacciones se ejecutarán principalmente en el navegador.

No implementar autenticación, pagos, base de datos ni backend empresarial sin una decisión justificada y aprobada.

## 8. Criterios de éxito

- Contenido claro, fundamentado y útil.
- Navegación sencilla y coherente.
- Experiencias visuales que ayuden a comprender.
- Interfaz profesional y accesible.
- Buen rendimiento.
- Proyecto mantenible y versionado con Git.
- Publicación web mediante Cloudflare.

## 9. Decisiones pendientes

Definir y validar:

- Índice editorial definitivo.
- Cantidad final de páginas.
- Sistema de diseño completo.
- Experiencias interactivas prioritarias.
- Componentes reutilizables.
- Criterios de aceptación por capítulo.
