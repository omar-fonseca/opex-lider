# ADR-0002 — Arquitectura multiagente Cursor

**Fecha:** 2026-11-14  
**Estado:** aceptado (configuración)  
**Motivo:** Especializar análisis/implementación 3D sin duplicar el director como sexto ejecutor.  
**Evidencia:** `.cursor/agents/*.md`, `AGENTS.md`, docs Cursor Subagents.  
**Alcance:** solo configuración de agentes/reglas/docs; cero cambios en `src/` / `public/`.  
**Commit relacionado:** `chore/opex-ai-agents-v1`

## Decisión
- Cinco subagentes: architect, pedagogy, 3d-art-director, 3d-engineer, quality-security.
- `model: inherit`; `readonly: true` en especialistas no escritores.
- Director = Cursor Agent principal (`AGENTS.md`).
- Equivalente Antigravity `opex-architecture-review` se conserva; no se duplica como sexto agente Cursor.

## Consecuencias
- Delegación selectiva; un escritor por archivo.
- Informes versionados bajo `docs/ai/reports/` cuando el ejercicio lo requiera.
